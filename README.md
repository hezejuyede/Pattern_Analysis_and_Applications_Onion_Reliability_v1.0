# Matched source replacement in plant image evaluation

The current research artifact is **v1.8.0**. Start with [v1.8/README.md](v1.8/README.md), the [current manuscripts](v1.8/manuscript/README.txt) and the [data/code license notice](v1.8/DATA_LICENSES_AND_ATTRIBUTION.md).

This release contains corrected onion source-component controls, a second task with original author-recorded potato leaf identifiers, a DINOv2 sensitivity, and one-source-at-a-time replacement experiments. It retains all model outcomes, complete prediction records, source assignments, fixed code and independently reconstructed statistics. The cached-input entry point is portable; image reacquisition and historical training have separately documented requirements.

The contribution is a bounded empirical evaluation of local exposure response, training-background sensitivity and changes on never-exposed images. A research release is not an editorial decision or a claim of new field validation. Neither audited visual components nor leaf identifiers establish independently sampled whole plants or common pathological adjudication.

## Scientific correction and history

The [2 October correction notice](audit/v16_research_gate/CORRECTION_NOTICE_20261002.txt) remains applicable to the historical augmented-prefix analyses. Old tags are immutable. Filename-prefix and early matched-sibling estimates are not current source-disjoint evidence; v1.8 uses corrected components and retains those limitations explicitly.

The [previous README](audit/release_v1.2.1/README.md) documents the historical branches. Older files remain at the repository root for provenance, including regional/calibration training and fixed transfer predictions. Their old image-resampling intervals should not replace the current 547/700-component sensitivity in [v1.8/supplementary_context](v1.8/supplementary_context/README.md). Use the current v1.8 directory for the replacement experiments and manuscripts.

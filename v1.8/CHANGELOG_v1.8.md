# Research changes in v1.8

This increment follows the scientific correction preserved in the public repository. Historical versions remain historical; their invalidated source-independence claims are not silently reinstated.

1. **Corrected source units and matched replacements (retained v17).** Uses saved corrected component/leaf assignments, fixed class budgets, matched donor removal and same-class alternates. Retains the original three fixed models, all saved splits, multiclass and secondary binary outcomes. The second archive is a task sensitivity, not a new field cohort.
2. **Modern fixed representation (v18).** Adds pretrained DINOv2 ViT-S/14 normalized CLS features with the same assignments and tests standardized balanced logistic regression and cosine 1NN. No tuning, case selection or stopping rule based on the new outcomes was introduced. Feature extraction alignment and source-code/checkpoint provenance are recorded; pretraining overlap remains unknown.
3. **One-source replacement controls (v18).** Changes only the target versus its matched alternate within each exposure/sham pair against the same zero background, for every paired target in the first ten saved splits. Preserves task-specific source/file budgets, all five models, and the fixed test anchors. Records full predictions and training membership.
4. **Class-weight sensitivity and context comparison.** Retains original-class averages and the explicitly post hoc common-class sensitivity. Reconstructs single/joint contrasts using matching splits and targets, rather than comparing ten-split and thirty-split means as a matched causal effect.
5. **Independent verification.** Reconstructs full raw-prediction summaries without importing experimental prediction or analysis routines. The original independent review used 96 logistic refits and 68 nearest-neighbour condition checks across the new v18 results. The separate portable smoke verification uses a smaller deterministic sample; its report lists its actual counts.
6. **Portable release and compression.** Preserves original frozen code and hashes. Introduces explicit relative-path adapters, exact string-cell Parquet conversions, upstream licensing separation and executable reconstruction/plotting commands. The original images and checkpoints are excluded.
7. **Source attribution correction.** The fixed COLD Hugging Face card cites Mendeley version 2, DOI `10.17632/7nxxn4gj5s.2`. The earlier unverified version-3 citation is not carried forward as established provenance. Dataset licensing is separate from the associated article's license.

These changes strengthen control design, numerical auditability and presentation. They do not establish independent plant identities for the onion archive, obtain pathological re-review, guarantee an external-review decision, or justify a self-assigned journal percentile.

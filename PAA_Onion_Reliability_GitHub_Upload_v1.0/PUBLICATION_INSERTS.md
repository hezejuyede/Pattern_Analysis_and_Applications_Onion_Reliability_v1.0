## Code and data availability

The analysis code, frozen splits, derived feature matrices, per-image model
outputs, result tables, integrity manifests and independent verification
artifacts are available at https://github.com/hezejuyede/Pattern_Analysis_and_Applications_Onion_Reliability_v1.0. Third-party source images
are not redistributed. Versioned download instructions, upstream licences and
SHA-256 records needed to reconstruct the analysed image sets are supplied in
the repository.

## Reproducibility statement

The repository includes an offline verification path that does not require
the source images and a full reconstruction path that downloads and verifies
the public image collections before feature extraction. The offline path
validates the frozen evidence only; it does not independently re-download or
re-hash the third-party images.
